# Autoqqpet（QQ 宠物自动托管）

一个 **libxposed / LSPosed** 模块，用于自动化 QQ 宠物。它会按"有效属性收益"来规划每天的
学习 / 工作 / 冒险，兼顾疲劳度并让金币自给自足；同时处理喂食、洗澡、购买食物、PK 与访问好友。
模块还带一个保活前台服务：实时状态通知（正在做什么 / 多久前心跳 / 多久后下次唤醒）+ 看门狗，
在 QQ 被系统杀掉冻结、或调度循环卡住时自动接回，不用你守着。

> ⚠️ 实验性工具。自动化游戏可能违反用户协议并带来账号风险，请自行评估、自担风险。

## 运行环境
- 框架：**LSPosed** 或 **Vector**（libxposed API 102，静态作用域 staticScope）
- 系统：Android 8.0 及以上（minSdk 26）
- 目标应用：**com.tencent.mobileqq**（QQ 9.3.65 已真机验证；其他版本可能因内部改名失效）

## 使用步骤
1. 安装并激活 LSPosed / Vector 框架；
2. 安装本模块 APK；
3. 在框架中启用本模块，并把作用域设为 **QQ（com.tencent.mobileqq）**（已为你预勾选）；
4. 打开 **Autoqqpet**，阅读并同意用户协议，选择目标属性并开启自动托管；
5. 通知栏会实时显示它在做什么；详细日志见 logcat，标签 `Autoqqpet`。

## 功能说明
- 日程规划：按有效属性收益择优安排 学习 / 工作 / 冒险，带每日上限与疲劳处理；学工不划算时优先冒险。
- 任务模式三选一：学习优先 / **工作优先**（有活先打工）/ 只重复冒险。
- **打工方向可选**：下拉框直接从服务器读出并只列出本账号实际解得开的职业（一个按钮刷新）；**时长档位不写死也不让人预设**，
  10 分钟 / 45 分钟 / 2 小时 / 4 小时 四个档每轮全部重读，拿当时的实时数字算净收益取最划算的那个（宠物疲劳时这些数字会整体下降，写死就会选到亏本档）；
  各职业算出来相等时只说“并列”，不标“最佳”。
- 日常照顾：喂食、洗澡、购买食物（饼干 / 香皂片用完自动补货，花游戏金币）；PK 与访问好友，附带好友黑白名单与每日次数上限。
- 被雇佣提醒：宠物被好友雇佣去干活时，进度一到 71%（这段区间的分成归我们拿大头）会弹通知，提醒去 QQ 里手动点「召回」腾回宠物；
  任务不在了自动撤销。不点也不会出错，到点照样正常结算。
- 精准调度：按任务时长定点唤醒、到期准确结算、失败有界重试；短延时走进程内精确定时，避开 Doze 的闹钟节流。
- 保活：前台服务 + 唤醒锁 + 实时状态通知 + 看门狗 + 开机自启。判活同时看「心跳是否新鲜」与
  「是否还排着未到期的唤醒」两件事，所以既能在 QQ 被杀后救回，也能在循环自己卡住时接回；
  救活动作 90 秒节流，跑 30 分钟的长任务期间不会被误判成挂死。
- **静默唤醒**：发现 QQ 不在时，看门狗先只把 QQ 进程拉起来（查它导出的 ContentProvider），**不会弹任何界面、不打断你当前在用的应用**；
  45 秒内没回应才退化成“拉到前台”兜底（那一步才需要下面提到的可选开关）。

## 关于「显示在其他应用上层」（可选）
Android 14 / One UI 起，后台应用默认不能把另一个应用拉回前台，而且被拦时**不报错**。因为唤醒已改成先走
“静默唤进程”（不弹界面），这个开关**只在静默唤不回来的偶尔情况**下才用得上——那时它能允许把 QQ 拉到前台兜底。

**本模块不会显示任何悬浮窗**：工程内没有任何悬浮窗绘制代码，屏幕上不会多小窗口、遮罩或动画，也不拦截点击；
它只读这个开关的状态作为系统豁免凭据。

**不授予也完全可用**：循环卡住仍会自动接回，静默唤醒也照常工作；随时可在系统设置里关闭。
